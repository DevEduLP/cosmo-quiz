## 6. Publicando a política de privacidade (GitHub Pages)

1. Suba a pasta `docs/` para o repositório `DevEduLP/cosmo-quiz` (precisa ser **público**).
2. No GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta **`/docs`** → Save.
3. Em ~1 minuto a página fica em:
   `https://devedulp.github.io/cosmo-quiz/privacy-policy.html` (o GitHub mostra o link exato na tela de Pages)
4. Abra o link numa aba anônima para conferir e cole no Play Console.
