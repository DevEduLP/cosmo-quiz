🌌 Cosmo Quiz

Aplicativo mobile desenvolvido com React Native e Expo, focado em testar conhecimentos sobre astronomia de forma interativa e dinâmica.

O app apresenta perguntas com sistema de pontuação em tempo real, explicação detalhada das respostas e funcionalidade de compartilhamento de resultados.

🚀 Funcionalidades

Sistema de perguntas e respostas

Controle de estado com React Hooks

Feedback imediato ao usuário

Tela final com pontuação

Explicação detalhada das respostas

Compartilhamento nativo de resultados

Interface otimizada para dispositivos móveis

💻 Como Executar o Projeto
Clone o repositório:

git clone https://github.com/DevEduLP/cosmo-quiz.git


Acesse a pasta:

cd cosmo-quiz


Instale as dependências:

npm install


Inicie o projeto:

npx expo start

🎯 Objetivo do Projeto

Praticar desenvolvimento mobile com React Native, gerenciamento de estado e organização de componentes, aplicando boas práticas de UI e lógica de aplicação.
